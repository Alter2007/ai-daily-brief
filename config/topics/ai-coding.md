# 主题：AI 编程与开发工具

写给每天写代码的人。关心的是"我明天要不要换工具"。

## 关心什么

模型、CLI、IDE 插件、Agent 框架的版本更新；能力/定价变化；破坏性变更。

## 分类

`#版本` `#能力` `#定价` `#破坏性变更`

## 加分词（命中 +10）

release 版本 更新 支持 新增 修复 废弃 breaking deprecated 开源 免费 降价 benchmark

## 减分词（命中 −10）

传闻 据悉 据说 或将 疑似 爆料

## 一手源加成

GitHub releases / 官方 changelog（`level: "first-party"`）+20 分。

## 输出规范

- 最多 5 条
- 每条必须带版本号或日期
- 优先报 breaking change
